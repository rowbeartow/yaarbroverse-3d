# Crocodile sound candidates: credits

All recorded, all CC0 as stated on each OpenGameArt page, downloaded on 2026-11-15. Each was made mono, cut to its sounding part with a soft start and a short fade out (nothing added at either end), had the rumble under 60 hertz taken out, had its loudest point set to -1 dBFS, and was saved as 16-bit WAV (22,050 hertz where the source has nothing above 11,000 hertz, else 44,100). Nothing else was changed unless the row says so. Rows go into the "Sound and music" table of CREDITS.md once the owner picks (the file name then drops its letter, e.g. `croc-warning.wav`).
