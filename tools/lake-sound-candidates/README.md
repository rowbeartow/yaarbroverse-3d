# Lake sound candidates (not in the game)

The candidates on the sound board for Cocolalla Lake, kept here so they are
not lost while the owner listens. Not wired into the game. Once the owner
picks, the chosen files move to `assets/audio/`, their rows go into
`CREDITS.md`, and this folder is deleted.

- `extras.json` and the files: the board's extras folder
  (`node tools/preview/sounds.mjs <board folder> tools/lake-sound-candidates`).
- `credits.md`: the CREDITS.md rows and checksums for the recorded ones.
- `make-loon.py`: the loon's wail, made in code (no CC0 loon recording was
  found): `python3 make-loon.py loon.wav` (needs numpy).
